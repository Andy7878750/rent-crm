# Расчётка

Веб-приложение для арендодателя: считает коммунальные платежи арендаторов по счётчикам и тарифам, выставляет счета, ведёт оплаты поставщикам.

- ТЗ: Claude Docs, «ТЗ: CRM для арендодателя (пилот, Россия)»
- Макет: claude.ai, «Расчётка — главный экран» (доски «Главный экран» и «Вход и регистрация»)

## Что уже есть

**Модуль расчёта** — `src/lib/calc/`. Без базы и интерфейса: на входе данные месяца, на выходе счёт каждого арендатора.

| Файл | Что внутри |
|---|---|
| `types.ts` | Услуги, тарифы, объекты, арендаторы, показания, результат |
| `engine.ts` | `calculateMonth()` — все логики расчёта из раздела 7 ТЗ |
| `format.ts` | Округление до копеек, форматы чисел, сумма прописью |

Логики: доля по квитанции, делится по показаниям, счётчики + остаток по долям, фиксированная, по счётчику, день/ночь, от других услуг, с нормативом, только арендодатель.

Правило округления: каждая строка до копеек, итог = сумма строк.

## Проверка

```bash
npm test
```

Тесты (`tests/calc.test.ts`) сверяют расчёт с реальными цифрами за август 2026: квитанции ПЕСК (15 845,80 и 20 938,90 ₽), ГУП ТЭК (2 147,94 ₽), итоги всех пяти арендаторов до копейки.
