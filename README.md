# Расчётка

Веб-приложение для арендодателя: считает коммунальные платежи арендаторов по счётчикам и тарифам, выставляет счета, ведёт оплаты поставщикам.

- ТЗ: Claude Docs, «ТЗ: CRM для арендодателя (пилот, Россия)»
- Макет: claude.ai, «Расчётка — главный экран» (доски «Главный экран» и «Вход и регистрация»)

## Что уже есть

- **Вход и регистрация** (почта + пароль). При регистрации создаётся пример объекта «Королёва 61» с арендаторами, услугами, тарифами и показаниями.
- **Меню разделами** (тёмная полоса + пункты раздела).
- **Объекты:** список со сводкой, создание и изменение (арендаторы или собственник), архив.
- **Страница объекта:** «Ввод данных» (счета на помещение, показания — сохраняются сразу) и «Расчёт» по выбранному арендатору, листание месяцев.
- **Модуль расчёта** — `src/lib/calc/`: все логики из раздела 7 ТЗ, тесты на реальных данных.

Остальные разделы меню пока показывают «В разработке».

## Запуск

```bash
cp .env.example .env          # адрес базы PostgreSQL
npm install
npm run db:migrate
npm run dev                   # http://localhost:3000
```

## Проверка

```bash
npm test
```

Тесты (`tests/calc.test.ts`) сверяют расчёт с реальными цифрами за август 2026: квитанции ПЕСК (15 845,80 и 20 938,90 ₽), ГУП ТЭК (2 147,94 ₽), итоги всех пяти арендаторов до копейки.
