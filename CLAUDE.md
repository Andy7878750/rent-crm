# Расчётка (rent-crm)

@AGENTS.md

CRM для арендодателя: коммунальные платежи арендаторов. ТЗ — Claude Docs «ТЗ: CRM для арендодателя (пилот, Россия)», макет — артефакт «Расчётка — главный экран».

## Стек
- Next.js 16 (App Router, `cacheComponents: false` — всё приложение за логином и динамическое), React 19, TypeScript, Tailwind 4.
- PostgreSQL + Drizzle ORM (`src/db/schema.ts`, миграции в `drizzle/`).
- Вход: свои сессии (scrypt + токен в httpOnly cookie, в базе хеш), `src/lib/auth/`.
- Модуль расчёта без зависимостей: `src/lib/calc/` — главный источник правды по суммам.

## Правила
- Каждое серверное действие само проверяет, что объект/услуга/арендатор принадлежит аккаунту пользователя.
- Суммы: строка округляется до копеек, итог = сумма строк. Любое изменение расчёта — сначала тест в `tests/calc.test.ts`.
- Тексты интерфейса — по-русски, термины как в ТЗ («Ввод данных», «Счета на помещение», «Остаётся на вас»).

## Команды
- `npm run dev` — разработка; `npm run build && npm start` — прод.
- `npm test` — тесты модуля расчёта (реальные цифры августа 2026).
- `npm run db:generate` — миграция из схемы; `npm run db:migrate` — применить.
- `.env`: `DATABASE_URL=postgres://…` (пример в `.env.example`).
